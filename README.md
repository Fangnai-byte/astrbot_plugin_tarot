# 塔罗占卜 (Tarot)

![logo](logo.png)

在群里丢一句 `/塔罗 要不要辞了这份工作`，回来一张画好的牌阵图，再加一段解读。

```
你问的是「要不要辞了现在这份工作」。
处境 · 权杖六（正位），这次的功劳是你的，认下来。
建议 · 圣杯侍从（逆位），情绪化，别人一句话能影响你一天。
结果 · 圣杯八（正位），有些东西拿到了却不想要，走也没关系。

整体顺，只有一两处别扭，把那一处解决掉。
```

78 张全牌组，正位逆位都有，图在本地用 Pillow 画，不联网。

版本 1.0.1，作者 Fangnai-byte，仓库 https://github.com/Fangnai-byte/astrbot_plugin_tarot

## 用法

```
/塔罗 [问题]            抽一局，用默认牌阵
/塔罗 十字 [问题]       指定牌阵，也可以写 /塔罗 用十字 ...
/塔罗 牌阵              看有哪些牌阵、每个位置什么意思
/塔罗 回看              翻上一局，牌不会变
/塔罗 牌 月亮           查一张牌，出卡片图
/塔罗 统计              自己最近抽过什么
/塔罗 群统计            本群一共抽了几局、几个人、出得最多的牌
/塔罗 帮助              命令说明
```

## 牌阵

抽之前先选牌阵，每个位置有自己的意思。同一张牌落在「阻碍」和落在「结果」，读法差得远。

| 牌阵 | 张数 | 位置 |
| --- | --- | --- |
| 单张 | 1 | 核心 |
| 时间流 | 3 | 过去 / 现在 / 未来 |
| 处境 · 建议 · 结果 | 3 | 你现在的真实位置 / 下一步能做的动作 / 照这个走法会落到的结果 |
| 关系三张 | 3 | 你 / 对方 / 你们之间 |
| 五张十字 | 5 | 现状 / 阻碍 / 潜在 / 建议 / 结果 |
| 凯尔特十字 | 10 | 现状 / 挑战 / 根基 / 过去 / 目标 / 近期 / 自己 / 环境 / 希望与恐惧 / 结果 |
| 二选一 | 6 | A 现状 / A 发展 / A 结果 / B 现状 / B 发展 / B 结果 |

五张十字和凯尔特十字照着传统摆法画。逆位的牌整张倒过来放，跟真牌摊在桌上一样。

牌阵名只认确切的词。以前「建议」「关系」也是牌阵名，结果有人问「建议我怎么办」，
前半句被吃掉当牌阵，剩下半句成了问题。现在要指定就写 `/塔罗 十字 ...` 或 `/塔罗 用十字 ...`。

## 抽牌是你自己报数字

它先回一句，让你报数。

```
时间流，3 张。牌洗好了，从 1 到 78 里报 3 个数。
```

你报 `7 21 34`，它按这三个数翻牌出图。数量不对、超范围、报重复都会提醒重报，
180 秒不报就作废。不想要这一步，把 `manual_draw` 关掉，它就自己抽、直接出图。

## 牌面

纸是米黄的，铺了低频色斑和细颗粒，撒几处很淡的霉斑，中间一道对折的痕。牌边故意画得略不齐，
像手裁的；框是双线压印，字和线都补了一层极淡的重影。

牌面是纸和字。墨线细框，罗马数字在上，牌名、英文、正逆位、关键词依次排在中间。
不放插画，所以每张牌的差别全在文字上。小牌左上角不写点数，牌名里已经有了。

想要图，`art/` 放 1909 年版韦特牌（公有领域）就行，跑一次 `tools_fetch_art.py` 会自己下，
`card_art` 打开后牌面换成牌图。图片不随仓库分发，见下面「安装」。

字体分两套。单张牌的大牌名和各图标题用 `font_style`（默认舒体），牌阵里的小牌名和位置标签用
`font_style_small`（默认楷体）。舒体在 20 像素左右会糊，所以小牌退回楷体。罗马数字固定宋体，
行楷写 V 和 I 会歪成斜线。可选的字体有舒体、行楷、楷体、隶书、姚体、中宋、新魏、仿宋。

试过星空紫加金色发光那套，第一张好看，看十张就腻。纸和墨耐看得多。

## 解读

每张牌按位置念一遍，再补几句牌与牌之间的关系。同花色出了三张，重心就在那块；
两张同数字，同一个课题又出现一遍；逆位集中在一头，问题出在开头或收尾；大阿卡纳过半，这事不小。
最后一句看逆位数量，多就说明卡在自己这边，没有就说明比你想的顺。

五张十字、凯尔特十字、二选一这三个会分段。局面一块、人和环境一块、结果一块，
中间空一行，不用连着读十行去猜哪张是收尾。五张以上的牌阵只写一行牌面加结论，不逐张铺牌义。

想要更像人聊的话，可以开 `llm_reading`，把牌阵和问题交给当前模型写一段。默认关着，省 token。
模型超时或报错就自动退回上面那套固定文案。

同一个问题在 12 小时内只让抽一次。想再抽，它会告诉你上次几点抽的、头一张是什么牌，
剩下的时间到了再问。只差个标点算同一个问题。要关掉就把 `question_lock_hours` 设成 0。

同一件事过了锁定期再问，解读前面会提一句上次是什么时候、头一张是什么牌。
用默认单张问感情或事业时，末尾会建议更合适的牌阵，只建议，不自动换。

## 统计

```
/塔罗 统计
最近抽了 12 局，36 张牌。
花色：圣杯 11 张、宝剑 9 张
重复最多：圣杯三 ×3、权杖八 ×2
逆位 12 张，占 33%。
```

只看自己，每人最多留 60 局。

```
/塔罗 群统计
本群一共抽了 12 局，35 张牌，4 个人抽过。
抽得最多：××8565 6 局
出得最多：宝剑六 ×3、圣杯七 ×2
逆位 11 张，占 31%。
```

群统计只算带群号的新记录。加群号之前的旧局算不进去。

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `card_enabled` | true | 关掉只回文字牌义 |
| `card_width` | 900 | 卡片宽度，640～1400 |
| `card_art` | false | 用韦特牌图。开启前先跑 `tools_fetch_art.py` 下载 |
| `font_style` | 舒体 | 单张大牌名与标题的字体 |
| `font_style_small` | 楷体 | 牌阵里小牌名与位置标签的字体 |
| `reversed_enabled` | true | 关掉只出正位 |
| `reversed_percent` | 35 | 逆位概率。真实占卜里逆位没到一半，默认 35 |
| `default_spread` | 时间 | 不指定牌阵时用哪个，默认抽三张 |
| `manual_draw` | true | 抽牌要先报数字，关掉就直接出图 |
| `manual_timeout_seconds` | 180 | 手动抽等你报数字的时限 |
| `question_lock_hours` | 12 | 同一个问题多少小时内只让抽一次，0 表示不拦 |
| `three_card_enabled` | true | 允许多张牌阵，关掉只能抽单张 |
| `reading_text` | true | 发完图再补一段解读 |
| `llm_reading` | false | 让模型写解读，费 token |
| `llm_max_chars` | 100 | 模型那段最长多少字，超了按句号截 |
| `llm_timeout_seconds` | 25 | 模型超时就退回固定文案 |
| `shuffle_notice` | true | 抽牌前先回一句「洗牌中」，关掉少一条消息 |
| `include_question` | true | 把问题印在卡片上（最多 24 字） |
| `footer_text` | 空 | 卡片底部小字，留空显示日期 |
| `cooldown_seconds` | 5 | 同一用户的冷却，0 表示不限 |
| `group_cooldown_seconds` | 10 | 同一个群的冷却。只按人限流拦不住群里轮流抽 |
| `allow_user_ids` | 空 | 只让这些人用，留空所有人 |

## 存了些什么

每抽一局记进 `data/plugin_data/astrbot_plugin_tarot/last_draw.json`，按人分开，最多 60 条，
`/塔罗 回看` 靠它重画上一局，不重新抽牌。

卡片图写在 AstrBot 的 temp 目录，只留最近 40 张。存 JPEG，质量 92，同样观感下体积是 PNG 的五分之一，
单张约 60 KB，十张约 190 KB。

## 安装

把 `astrbot_plugin_tarot` 整个目录放进 `data/plugins/`，面板里启用。没有额外依赖，AstrBot 自带的 Pillow 就够。
出图失败会退回文字，不会不回话。

### 牌图（可选）

仓库里不带牌图，`art/` 默认是空的，牌面走纯文字那套。想要牌图就跑一次脚本。

```bash
cd data/plugins/astrbot_plugin_tarot
python tools_fetch_art.py      # 从 Wikimedia 下 1909 年版，约 4 MB
```

下完把 `card_art` 打开。脚本会自己裁成 3:5、压成 300×500，重复跑只补缺的那几张。
先试系统代理，走不通再试直连；两个都不行才跳过。没网也不影响抽牌，牌面自动退回文字。

牌图取自 1909 年版，画者 Pamela Colman Smith 1951 年去世，按各国保护期算都已进入公有领域；
文件来自 Wikimedia Commons，这里只做了缩放、灰度、裁边和染纸色。

名称上避开了「Rider-Waite」，那是 U.S. Games 的商标，这里只用「1909 年版韦特牌」
这种描述；也没用他们后来重制的彩色修复版，只用 1909 年原版扫描件。
